📋 Pre-Requisites

Complete the following activities before initiating the device migration.

Step 1 - Collect User & Device Information
Technician Action

Collect and verify the required details before initiating the migration.

  • User Full Name
  • Username
  • Email Address
  • Hostname / Computer Name
  • Asset Tag (if applicable)
  • Current IP Address (optional)
  • Current OU / Device Status (if required)
Information Ensure the correct user and corresponding device are selected for migration to avoid account mapping issues.
Step 2 - Disable Trellix Single Sign-On (SSO)
Critical

Disable Trellix Single Sign-On (SSO) for the user before beginning the migration.

Important Failure to disable Trellix SSO may prevent successful authentication after the migration.
Step 3 - Close All Applications
User Action

Request the user to save all work and completely close every application.

  • Microsoft Outlook
  • Microsoft Teams
  • OneDrive
  • Office Applications
  • VPN Clients
  • Browsers
  • Any applications with unsaved work
Warning Unsaved work may be permanently lost during the migration and mandatory system reboots.
Step 4 - Verify Network Connectivity
Critical

Ensure the laptop is connected directly to the corporate office network.

  • Office LAN Connection (Preferred)
  • Office Wi-Fi
  • Disconnect VPN before starting
Do NOT Do not perform the migration while connected through VPN.
Requirement The laptop must remain connected to the Office Network throughout the migration process.
Step 5 - Configure Power Options
Technician Action

Configure the Windows Power Plan to prevent the device from entering Sleep mode.

  • Open Control Panel
  • Select Power Options
  • Choose Balanced
  • Select Change Plan Settings
  • Configure Turn off display as required
  • Set Put the computer to sleep = Never
Important The device must remain powered on during the complete migration process.
Step 6 - Verify Quest On Demand Migration Agent
Technician Action

Verify whether the Quest On Demand Migration Agent is already installed.

6.1 Check Installed Programs

  • Press Win + R
  • Run appwiz.cpl
  • Verify whether the Quest On Demand Migration for Active Directory Agent exists.
appwiz.cpl
If the agent exists Proceed to the next migration step.
If the agent is NOT installed Follow the installation procedure below.

6.2 Copy Quest Agent

Browse to the following shared folder.

\\10.175.5.89\QuestODM\2 Mindsprint

Copy the entire Quest-ODM folder to:

C:\

6.3 Install the Agent

Navigate to:

C:\Quest-ODM

Run the following as Administrator.

MS-AD-Install.bat

6.4 Refresh the Agent

After successful installation, execute:

Registry_repair.bat
Success Criteria Quest On Demand Migration Agent is installed and refreshed successfully.

🔄 During Cutover

Perform the following activities during the scheduled migration window.

Step 7 - Refresh Quest ODM Agent (If Required)
Technician Action

If instructed by the Migration Team, refresh the Quest On Demand Migration Agent.

Navigate to:

C:\Quest-ODM

Run the following as Administrator.

Registry_repair.bat
Important Run this step only when explicitly instructed by the Migration Team.
Step 8 - Device Migration & Reboots
Reboot Required

The migration process will automatically reboot the device twice.

First Reboot

  • Allow the reboot to complete.
  • Log in to Windows using the existing credentials.
  • Do not interrupt the migration process.

Second Reboot

  • Disable Trellix Single Sign-On.
  • Connect to the corporate Wi-Fi.
  • Authenticate using Mindsprint.local\username.
  • Sign in to Windows using Mindsprint.local\username.
Warning Do not power off the laptop or disconnect it from the corporate network during either reboot.
Success Criteria The user successfully logs in using the new Active Directory credentials.
Step 9 - Configure Microsoft 365 Applications
User Action

Sign in to all Microsoft 365 applications using the new mindsprint.com account.

  • Microsoft Outlook
  • Microsoft Teams
  • Microsoft OneDrive
  • Microsoft Office Apps (Word, Excel, PowerPoint, etc.)
Information Verify that Outlook mailbox loads successfully and OneDrive begins syncing before proceeding.
Step 10 - Configure Microsoft Edge Profile
User Action

Launch Microsoft Edge and configure the browser profile.

  • Sign in using the mindsprint.com account.
  • Enable profile synchronization.
  • Verify bookmarks and settings begin synchronizing.
Verification The Edge profile displays the new organizational account and synchronization status is active.

✅ Post Migration

Complete the remaining post-migration activities before handing the device back to the user.

Step 11 - Configure Network Printer
Technician Action

Configure the network printer using the Print Management Portal.

Open the following URL in a browser:

inchn-print01:8082/login/company
  • Sign in using Mindsprint.local credentials.
  • Create a new Printer PIN if prompted.
  • Install the required printer(s).
  • Print a test page to verify successful configuration.
Information Ensure the user can authenticate successfully before installing printers.
Verification Required printers are visible and a test print completes successfully.
Step 12 - Remove Stale Entra Device Registrations
Technician Action

Remove obsolete Entra registrations associated with the migrated user.

  • Open the Microsoft Intune Admin Center.
  • Locate the migrated user.
  • Review all associated Windows devices.
  • Identify duplicate or stale Entra registrations.
  • Delete only obsolete registrations after confirming the active migrated device.
Important Verify the active Hybrid Entra joined device before removing any stale registrations.
Verification Only the current migrated device remains associated with the user.
Step 13 - Trellix Authentication
Critical

Continue using manual authentication for Trellix until the migration team confirms ePO migration completion.

  • Launch Trellix.
  • Keep Single Sign-On disabled.
  • Authenticate manually using the assigned credentials.
  • Continue this process until official confirmation is received from Satya.
Do Not Do not enable Trellix Single Sign-On until the ePO migration has been officially completed.
Migration Dependency Await confirmation from Satya before enabling Trellix SSO.
Step 14 - Verify Hybrid Entra Join & Intune Enrollment
Verification

Confirm successful Microsoft Hybrid Entra Join and Intune enrollment.

  • Verify the device is Hybrid Entra Joined.
  • Confirm Intune enrollment is successful.
  • Ensure policy synchronization has completed.
  • Confirm compliance status.
  • Obtain final confirmation from Prashanth N.
Success Criteria The migrated device appears in Microsoft Intune as Hybrid Entra Joined and compliant.
Note Do not close the migration ticket until enrollment has been verified.
